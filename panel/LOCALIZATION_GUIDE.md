# Руководство по локализации

## Автоматическое определение языка

Приложение автоматически определяет язык пользователя из настроек браузера. Поддерживаются следующие языки:
- `en` - English
- `ru` - Русский

Если язык браузера не поддерживается, по умолчанию используется английский.

## Ручная смена языка

Для программной смены языка можно использовать следующий код в консоли браузера или в компоненте:

```javascript
import i18n from '@/i18n';

// Переключить на русский
i18n.changeLanguage('ru');

// Переключить на английский
i18n.changeLanguage('en');
```

Выбранный язык автоматически сохраняется в localStorage и будет использоваться при следующем посещении.

## Добавление новых переводов

1. Переводы находятся в директории `/app/panel/resources/lang/`
2. Структура: `/app/panel/resources/lang/{locale}/{namespace}.php`
3. Например: `/app/panel/resources/lang/ru/dashboard/account.php`

### Пример файла перевода:

```php
<?php

return [
    'title' => 'Обзор аккаунта',
    'email' => [
        'title' => 'Обновить адрес электронной почты',
        'label' => 'Электронная почта',
    ],
];
```

## Использование переводов в компонентах

```typescript
import { useTranslation } from 'react-i18next';

const MyComponent = () => {
    const { t } = useTranslation('dashboard/account');
    
    return (
        <div>
            <h1>{t('title')}</h1>
            <p>{t('email.label')}</p>
        </div>
    );
};
```
